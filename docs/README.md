# Docs

- `referencia/`: cómo funciona cada sistema del juego (mundo, progreso, social y UI, lugares, festivales). Se actualiza en el mismo PR que cambia el sistema.
- `planes/`: planes de trabajo (`plan-*.md`): cabaña, rediseño, estructuras, casas, historia, festivales, carnaval y equipos.
- `arte/`: estándar de arte, auditoría de piezas y guía de carrozas.
- `despliegue.md`: Vercel, Render, Neon y LiveKit.
- `img/`: capturas del README.
